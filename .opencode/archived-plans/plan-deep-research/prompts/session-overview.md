# Session: plan-deep-research

Create the `plan-deep-research` planning mode — a collaborative, research-centric planning variant. When activated, it designs the scope of a research session. When the resulting plan is activated, HW and the user conduct the research together iteratively, culminating in a completed research report.

## What This Session Does

3 subtasks, no gate nodes, no loop nodes.

- **ST1** — Write `opencode/planning/plan-deep-research/plan.json` + 4 planning prompt files (`research-intake.md`, `clarify.md`, `research-gate.md`, `agent-routing.md`)
- **ST2** — Write `opencode/planning/plan-deep-research/prompts/finalize.md` — the terminal planning node that generates the full activated research session structure (plan.json + prompt files for the research session itself)
- **ST3** — Wire: add `plan_deep_research` tool to `opencode/plugins/planning-enforcement.ts`, create `opencode/commands/plan-deep-research.md`, update `opencode/agents/headwrench.md` Plan Types section

## Key Design Decisions

- The **planning session** (`/plan-deep-research`) is for scoping: what topic, what questions, what depth, what output format
- The **activated session** (generated by finalize.md) is collaborative: HW + user conduct research iteratively; HW dispatches @DeepResearcher, surfaces findings, user steers
- The activated session's `research-execute` node loops with `remaining_visits: 5` by default; `finalize.md` asks the user to confirm this during planning
- The activated session produces a **completed research report** — not stubs
