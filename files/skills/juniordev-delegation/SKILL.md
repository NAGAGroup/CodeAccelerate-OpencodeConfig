# Delegating to @junior-dev

Dispatch @junior-dev for goal-oriented code implementation.

## How to Dispatch

Call task tool with: `subagent_type="junior-dev"`, description (3-5 words), goal-based prompt with goal, context, scope boundaries, and constraints.

## What @junior-dev Does

- Goal-oriented implementer
- Investigates code using semantic search and tracing
- Makes targeted changes to achieve goal
- Reads and edits files; does not run commands, build, or write documentation

## Rules
- State goal clearly and why it matters
- Provide relevant context about where code lives
- Describe scope boundaries precisely: what to change and what to leave alone
- State constraints clearly
- Let agent investigate and decide how to implement
- More context produces better decisions
