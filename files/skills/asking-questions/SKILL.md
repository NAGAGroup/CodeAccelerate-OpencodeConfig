# Asking Questions

Load this skill whenever you need to gather user input that blocks your work.

## How to Call the Tool

Call the question tool with a concise question parameter. For approval gates with clear options, include an options array. For clarifications requiring quick user input, provide just the question parameter.

## Rules for Good Questions

Ask one question at a time—each call contains a single, focused question. Keep questions short and direct—one sentence maximum. Use the question tool only for quick input that cannot be inferred. Between questions, use sequential-thinking_sequentialthinking to reason about answers and whether more information is needed. Ask only when you have genuine uncertainty that blocks your work, not for decisions you can make yourself. Do not use the question tool for investigation work requiring expert delegation—use task dispatch instead.
