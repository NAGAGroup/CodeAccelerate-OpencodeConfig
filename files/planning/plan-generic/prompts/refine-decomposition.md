# Refine Decomposition

Your task is to **refine the decomposition based on evaluation feedback**.

## What to Do

Adjust:
1. Subtask boundaries (merge, split, or redefine)
2. Scope (make too-broad subtasks narrower, too-fine ones broader)
3. Dependencies (clarify or reorder)
4. Success criteria (make more explicit)

## Output

- Refined subtask list with changes noted

Call `next_step({ next: "evaluate-decomposition" })` to re-evaluate.
