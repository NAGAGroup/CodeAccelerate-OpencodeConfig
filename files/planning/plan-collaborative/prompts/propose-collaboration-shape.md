# Propose Collaboration Decomposition

Your task is to **break the design work into 3-7 collaborative turns**.

## What to Do

Decompose the collaboration:
1. List 3-7 design steps with clear names (e.g., "initial-proposal", "stakeholder-feedback", "refinement", "final-review")
2. For each step, explain: what will be designed/explored and what user input is needed
3. Identify decision gates: where does the user approve, redirect, or request refinement?
4. Identify loops: do any design steps need iteration?
5. Define success per step: when is each turn complete?

Each step should be a clear turn in the conversation with specific deliverables and feedback points.

## Output

- Numbered list of collaboration steps
- Brief description of each
- User input needed at each step
- Decision gates and their criteria
- Success definition per step

Call `next_step()` to evaluate.
