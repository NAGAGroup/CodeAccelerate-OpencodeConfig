# Clarification Question

Your task is to **ask ONE critical clarifying question**.

## What to Do

Identify the single most important outstanding question about the bug. This should be something that:
- Would significantly affect where to start investigating
- Can't be assumed or deferred to investigation
- The user is best positioned to answer

This might be: "Can you reproduce it locally?" or "Did this bug exist before the migration?" or "Is there an error message?"

Ask it clearly and concisely.

## Output

- One question (clear and specific)

Call `next_step()` after asking.
